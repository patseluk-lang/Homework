# Декоратори

Домашнє завдання з теми «Декоратори» — курс Python, DAN.IT Education.

## Умова

Написати декоратори, які перехоплюють типові помилки часу виконання
і коректно завершують програму з повідомленням замість аварійного
трасування стека.

## Реалізовано

**Декоратори**

- `check_division_error` — перехоплює `ZeroDivisionError`, друкує назву
  функції, у якій сталося ділення на нуль, і завершує програму з кодом 1
- `check_index_error` — перехоплює `IndexError`, друкує назву функції,
  у якій індекс вийшов за межі списку, і завершує програму з кодом 1

Обидва використовують `functools.wraps`, тому декоровані функції
зберігають власне ім'я та документацію.

**Функції для перевірки**

- `divide(a, b)` — ділення, обгорнуте `@check_division_error`
- `get_element(lst, idx)` — доступ до елемента списку,
  обгорнутий `@check_index_error`

## Запуск

```bash
python decorators_task.py
```

Спершу виконуються коректні виклики обох функцій, далі — помилковий.
Оскільки декоратор завершує програму на першій же помилці, у блоці
`__main__` помилкові виклики перевіряються по черзі: один рядок
розкоментувати, другий закоментувати.

Використано лише стандартну бібліотеку Python — додаткові пакети не потрібні.
