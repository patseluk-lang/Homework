# Пошук простих чисел

Домашнє завдання з курсу Python (DAN.IT Education): пошук простих чисел у заданому
діапазоні в однопотоковому та багатопотоковому варіантах з порівнянням швидкодії.

## Файли

| Файл | Призначення |
| ---- | ----------- |
| `search_for_prime_numbers.py` | Уся реалізація: функції, тести, вимірювання часу, аналіз |

## Запуск

```bash
python search_for_prime_numbers.py
```

Сторонні бібліотеки не потрібні — використано лише стандартні модулі
`math`, `threading`, `time`.

## Реалізація

| Функція | Що робить |
| ------- | --------- |
| `is_prime(n)` | Перевіряє, чи є число простим. Відсіює парні та перебирає лише непарні дільники до `sqrt(n)` |
| `find_primes_single_thread(start, end)` | Знаходить усі прості числа в діапазоні в одному потоці |
| `find_primes_multi_thread(start, end)` | Ділить діапазон навпіл і рахує кожну половину в окремому потоці, потім об'єднує результати |
| `measure(func, start, end)` | Повертає результат функції та час її виконання |
| `run_tests()` | Тестові випадки: перевірка `is_prime` і збіг результатів обох функцій на шести діапазонах |
| `compare_performance()` | Вимірює й порівнює час обох варіантів на чотирьох діапазонах |

## Результати

Багатопотоковий варіант не дає виграшу, а на малих діапазонах працює навіть
повільніше за однопотоковий.

Причини:

1. **GIL.** У CPython байткод одночасно виконує лише один потік. Пошук простих
   чисел — CPU-bound задача, тому потоки не рахують паралельно, а по черзі
   отримують GIL.
2. **Накладні витрати.** Створення потоків, перемикання контексту й об'єднання
   результатів забирають час, який на малих діапазонах перевищує будь-яку користь.
3. **Нерівномірний розподіл роботи.** Діапазон ділиться навпіл за значенням, а не
   за складністю: перевірка більших чисел вимагає більше ітерацій, тому другий
   потік завершує роботу пізніше й визначає загальний час.

Багатопотоковість була б ефективною для задач вводу-виводу (мережа, файли, база
даних), де потік звільняє GIL під час очікування. Реальне прискорення саме тут дав
