# Система реєстрації та входу користувачів (sqlite3)

Навчальний проєкт: база даних користувачів і система логування, реалізована у вигляді класу на Python з використанням модуля `sqlite3`.

## Можливості

- реєстрація нового користувача (`username`, `password`, `email`);
- вхід у систему з перевіркою даних у базі;
- обробка помилок: дублікат `username`, дублікат `email`, помилки БД;
- текстове меню в консолі.

## Структура таблиці

Таблиця `users` створюється автоматично при першому запуску.

| Поле | Тип | Обмеження |
|---|---|---|
| `id` | INTEGER | PRIMARY KEY, AUTOINCREMENT |
| `username` | TEXT | UNIQUE, NOT NULL |
| `password` | TEXT | NOT NULL |
| `email` | TEXT | UNIQUE, NOT NULL |

## Клас `User`

| Метод | Призначення |
|---|---|
| `__init__(self, username, password, email)` | Ініціалізує нового користувача |
| `register(self)` | Зберігає користувача в базу. Повертає `True` / `False` |
| `login(self, username, password)` | Перевіряє наявність користувача. Повертає `True` / `False` |

## Запуск

Сторонні бібліотеки не потрібні — `sqlite3` входить до стандартної бібліотеки Python.

```bash
python users_app.py
```

Файл бази `users.db` створюється в поточному каталозі.

## Технічні деталі

- Усі запити виконуються з параметрами-плейсхолдерами (`?`) — захист від SQL-ін'єкцій.
- З'єднання закривається в блоці `finally`; транзакціями керує контекстний менеджер `with conn`.
- `sqlite3.IntegrityError` розрізняється за текстом помилки (`users.username` / `users.email`).

## Обмеження

Паролі зберігаються у відкритому вигляді — так вимагає умова навчального завдання. У реальному застосунку слід використовувати хешування (`hashlib`, `bcrypt`).
